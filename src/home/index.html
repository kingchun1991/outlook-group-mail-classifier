Group Mail Classifier for Outlook

Classify Outlook messages by group recipients, apply categories, and optionally move messages to configured folders.

GitHub repository README manifest.xml

Quick Start

Install dependencies with npm ci, run npm start for local development, or run npm run build to create the production files in dist.

Outlook Installation

  • OWA: Get Add-ins > My add-ins > Add a custom add-in > Add from file.
  • New Outlook: More apps / Get Add-ins > My add-ins > Add a custom add-in > Add from file.
  • Desktop Outlook: Home > Get Add-ins > My add-ins > Add a custom add-in > Add from file.

Upload manifest.xml, then open a message and choose Mail Classifier.

Configuration Example

Single Rule Example

Rule Name: AIOps
Group Email: aiops@company.com
TO_ONLY: AIOps Direct
TO_INCLUDED: AIOps Shared
CC_ONLY: AIOps FYI
CC_INCLUDED: AIOps Monitor

Multiple Rule Example

AIOps, NOC, SOC, Finance, HR, and Service Desk can each have their own group mailbox and folders. The first matching rule wins.

Rules are stored per user. Changes made in Settings are stored inside Outlook and take effect immediately.

Notice: This public website only hosts the application. User rules are not stored in GitHub; they are stored in Outlook Roaming Settings.
